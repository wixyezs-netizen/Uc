# UC Shop Bot

Телеграм-бот для продажи UC (Unknown Cash, PUBG Mobile) с каталогом, оплатой
через ЮMoney, реферальной системой и админ-панелью — по типу ботов вроде PayCore.

## Возможности

- 🛒 Каталог пакетов UC с ценами (редактируется из админки)
- 💳 Оплата через ЮMoney (карты РФ, СБП, баланс кошелька)
- 🔄 Автоматическая проверка оплаты (фоновая задача) + кнопка ручной проверки
- 🤝 Реферальная система — % от покупок приглашённых начисляется бонусом
- 🛠 Админ-панель: статистика, список оплаченных заказов, выдача/отмена, управление товарами
- 🗄 Хранение данных в SQLite (легко переносится на PostgreSQL при желании)

## Как это работает

Так как у UC нет официального публичного API для мгновенного пополнения аккаунта,
бот работает по стандартной для таких магазинов схеме:

1. Пользователь выбирает пакет → вводит свой Player ID → получает ссылку на оплату.
2. Оплачивает через ЮMoney.
3. Бот сам проверяет поступление оплаты (раз в 20 сек) и подтверждает заказ.
4. Админ вручную пополняет UC через официальный сайт/приложение пополнения PUBG Mobile
   и нажимает «Выполнен» — покупателю приходит уведомление.

Если нужна полностью автоматическая выдача — это делается только через сторонние
реселлерские API пополнения UC (их нужно подключать отдельно, у каждого поставщика свой API).

## Установка

```bash
git clone <этот проект>
cd uc_shop_bot
python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

Заполните `.env`:

- **BOT_TOKEN** — получить у [@BotFather](https://t.me/BotFather)
- **ADMIN_IDS** — ваш Telegram ID (узнать у [@userinfobot](https://t.me/userinfobot)), через запятую если админов несколько
- **YOOMONEY_WALLET** — номер вашего кошелька ЮMoney (получатель платежей)
- **YOOMONEY_TOKEN** — токен доступа к API истории операций:
  зарегистрируйте приложение на https://yoomoney.ru/myservices/online и получите
  access_token с правом `operation-history`. Пошагово: https://yoomoney.ru/docs/wallet/using-api/authorization/basics

## Запуск

```bash
python main.py
```

При первом запуске автоматически создастся SQLite база и добавится стартовый
каталог пакетов UC (60/325/660/1800/3850/8100 UC) — их можно отредактировать
или удалить прямо в админке.

## Админ-панель

Команда `/admin` в боте (доступна только ID из ADMIN_IDS):

- **Статистика** — пользователи, заказы, выручка
- **Заказы в обработке** — оплаченные заказы, ожидающие ручной выдачи UC
- **Товары** — добавление/включение/выключение/удаление пакетов

## Замена ЮMoney на QIWI или Telegram Payments

Вся логика оплаты изолирована в `bot/payments/yoomoney.py` (2 функции:
`generate_payment_link` и `check_payment`). Чтобы подключить QIWI P2P API или
Telegram Payments — реализуйте такой же модуль с этими двумя функциями и
замените импорт в `bot/handlers/user.py` и `main.py`.

## Структура проекта

```
uc_shop_bot/
├── main.py                  # запуск бота + фоновая проверка оплат
├── requirements.txt
├── .env.example
└── bot/
    ├── config.py             # настройки из .env
    ├── database.py           # модели и функции БД (SQLAlchemy async)
    ├── keyboards.py           # inline-клавиатуры
    ├── states.py              # FSM состояния
    ├── handlers/
    │   ├── user.py            # каталог, покупка, оплата, профиль, рефералка
    │   └── admin.py           # админ-панель
    └── payments/
        └── yoomoney.py        # интеграция с ЮMoney
```

## Важно

- Это MVP, готовый к доработке под ваш проект. Перед боевым запуском рекомендуется:
  протестировать оплату на небольших суммах, добавить логирование в файл,
  подключить нормальную БД (PostgreSQL) при высокой нагрузке.
- Соблюдайте условия использования ЮMoney и правила PUBG Mobile Corp в отношении
  продажи внутриигровой валюты третьими лицами.
